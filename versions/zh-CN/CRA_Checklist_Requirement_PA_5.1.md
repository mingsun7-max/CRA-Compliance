# **第 1 节：引言与范围**

本文件规定组织的欧盟《网络韧性法案》（CRA）合规计划，其结构与 OpenChain 项目采用框架及 ISO/IEC 18974（开源安全保障）对齐，兼作政策框架与自我认证清单。

CRA（欧盟第 2024/2847 号条例）对投放欧盟市场的含数字要素的产品（PDE）规定了强制性网络安全要求。以下角色定义取自 CRA 第 3 条：

**角色定义（CRA 第 3 条）：**

● 制造商（第 3 条第 (13) 项）：开发或制造 PDE，或委托他人设计或制造 PDE，并以其自身名称或商标销售该产品的自然人或法人，无论该产品是有偿、免费，还是作为产生货币收入的服务提供。

●  进口商（第 3 条第 (17) 项）：在欧盟设立，将标有欧盟境外自然人或法人名称或商标的含数字要素的产品投放市场的自然人或法人。

●  分销商（第 3 条第 (18) 项）：供应链中除制造商或进口商之外，在欧盟市场提供含数字要素的产品的自然人或法人。

● 开源软件管理者（OSS Steward；第 3 条第 (14) 项）：制造商以外，持续为符合自由和开源软件（FOSS）条件的产品开发提供支持，并确保这些产品可持续存续的法人。开源软件管理者的定义、范围和义务规定于 CRA 第 3 条第 (14) 项、序言第 18、19 段及第 24 条。

**本文件的范围：**

● 由 [填写：制造商法定全称] 投放欧盟市场的所有含数字要素的软件产品

● 已发布产品中包含的开源组件

● 软件供应链流程，包括 SBOM 生成、漏洞管理和披露

● 参与开发、安全运营、法律及合规工作的人员与流程

硬件范围说明：硬件专属要求（包括 §3.1.7 硬件物料清单）仅适用于包含实体硬件组件的产品。仅提供软件的组织可以将硬件专属检查项标为“不适用（N/A）”，并记录理由。
